# AZAORI の追加サンプル

このフォルダの `.azo` ファイルは、成績処理、文字処理、対話入力の例です。CLI から実行できます。

```sh
cargo run --release -- test/01_成績処理.azo
cargo run --release -- test/02_文字処理.azo --kaki
cargo run --release -- test/03_数当て.azo
```

| ファイル | 内容 |
| --- | --- |
| `01_成績処理.azo` | 平均、同点を考慮した順位、合格判定、合格者一覧 |
| `02_文字処理.azo` | 文字数、空白・句点の除去、単語分割と整列 |
| `03_数当て.azo` | 1から100の乱数を7回以内に当てる対話プログラム |

最初の2本には `検` による結果確認が入っています。数当てでは、入力は半角の `1` から `100` を使い、`やめる` で終了します。
